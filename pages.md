# GitHub Pages deployment configuration

# This file is not used by GitHub Pages directly, but documents the setup.
# The site is built from the `index.html` at the repository root.

# To enable:
# 1. Go to Settings → Pages in the repository
# 2. Build and deployment → Source: Deploy from a branch
# 3. Branch: `main`, Folder: `/ (root)`
# 4. Click Save
# 5. The site will be published at https://switchboard-si.github.io/harness-adapter/
